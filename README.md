# 🛡️ KeyPulse — Система Лицензирования и Одноразовых Ключей

Полноценный бэкенд и веб-панель управления лицензионными ключами с базой данных SQLite и защитой от повторного ввода (привязка к железу / HWID).

---

## 🚀 Быстрый запуск

### 1. Запуск сервера:
Запустите файл `run.bat` или выполните команду:
```bash
python -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
```
После запуска откройте в браузере: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

### 2. Запуск клиентского приложения (Тест):
```bash
python client_demo.py
```

---

## ✨ Возможности веб-панели (Dashboard)

1. **Генерация ключей:**
   * Выбор количества (от 1 до 500 штук за раз).
   * Выбор префикса (`PRO-`, `VIP-`, `GAME-` и т.д.).
   * Выбор срока действия (Бессрочный, 1 день, 7 дней, 30 дней, 1 год).
   * Примечания к партии ключей (например: *«Для клиента @username»*).
2. **Защита от повторного использования:**
   * Первый пользователь активирует ключ — ключ навсегда связывается с его **HWID** (отпечатком железа).
   * Никто другой этот ключ активировать не сможет (сервер вернет `409 Conflict`).
3. **Управление ключами:**
   * 🔄 **Сброс HWID:** позволяет освободить ключ, если пользователь сменил компьютер.
   * ⛔ **Блокировка / Разблокировка:** мгновенное отключение доступа пользователю.
   * 🗑️ **Удаление:** удаление ключа из базы.
   * 📋 **Экспорт:** скачивание свободных ключей в `.txt` файл одной кнопкой.
4. **Интерактивный симулятор:**
   * Прямо в браузере (кнопка *«Тестер клиента»*) можно протестировать ввод ключа с разных виртуальных устройств.

## 📡 API Эндпоинты

### Для вашего приложения:

#### 1. Активация ключа (Одноразовая)
* **Метод:** `POST /api/client/activate`
* **Тело запроса:**
```json
{
  "key": "PRO-A1B2-C3D4-E5F6",
  "hwid": "HWID-USER-PC-UNIQUE-ID"
}
```
* **Ответ при успехе:** `200 OK`
```json
{
  "success": true,
  "message": "Ключ успешно активирован и привязан к вашему устройству!",
  "expires_at": "2026-11-13 19:00:00",
  "is_lifetime": false
}
```
* **Ответ, если ключ уже использован чужим человеком:** `409 Conflict`

#### 2. Проверка доступа при каждом запуске
* **Метод:** `POST /api/client/verify`
* **Тело запроса:**
```json
{
  "hwid": "HWID-USER-PC-UNIQUE-ID"
}
```
* **Ответ:** `200 OK`
```json
{
  "valid": true,
  "message": "Лицензия действительна.",
  "key": "PRO-A1B2-C3D4-E5F6"
}
```

## 🌐 Как бесплатно опубликовать в интернет (24/7)

1. Загрузите файлы этого репозитория на **GitHub**.
2. Зарегистрируйтесь на **[Render.com](https://render.com)** (полностью бесплатный тариф).
3. Создайте **New Web Service** → выберите ваш репозиторий.
4. Укажите:
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `uvicorn app:app --host 0.0.0.0 --port $PORT`
5. Вы получите бесплатный публичный адрес (например: `https://my-keys-api.onrender.com`), который можно прописать в `client_demo.py` или на вашем сайте!
